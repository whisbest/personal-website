数据库智能索引构建平台

Intelligent Index Builder：基于查询负载分析推荐索引组合，自动构建并检查索引收益，支持动态更新推荐结果。

我的贡献：参与团队项目，完成 SQL 负载分析、候选索引收益评估、贪心剪枝推荐及构建后的执行代价反馈。

项目概述

Intelligent Index Builder 是面向关系型数据库的智能索引推荐与自动构建平台。项目时间为 2024.11–2024.12，属于团队项目，已取得软件著作权。

查询负载分析

基于 JSQLParser 解析 SQL，结合 EXPLAIN 执行计划与 information_schema 统计信息，分析字段区分度和选择率，为候选索引提供收益评估依据。

推荐算法

设计贪心剪枝算法，通过代价估算筛选高收益索引组合，缓解候选组合数量的指数级增长，并支持动态更新推荐结果。

构建与反馈

采用 LOCK=NONE 选项创建索引，构建完成后通过 EXPLAIN 对比前后执行代价。若索引没有显著收益，则删除该索引。

我的工作

参与实现 SQL 解析与负载分析、候选索引收益评估、贪心剪枝及索引构建后的反馈流程。
